# Image needed for this page

The hero now uses ONE photo as a full-bleed background: an organized,
well-arranged fresh produce market (not a spice souk). Save it in this
folder as exactly:

    market-produce.jpg

## Option A — use your own photo (recommended)

Just save your photo here as `images/market-produce.jpg` (landscape/wide
shots work best — roughly 1600×900 or wider, since it fills the full
width of the screen behind the headline). No code changes needed, the
page already points at this filename.

## Option B — use the stock photo I picked

A free-licensed Unsplash photo of produce neatly arranged in wooden
crates — landscape orientation, works well as a background banner.

Download: https://images.unsplash.com/photo-1757627550652-30788bfce978?fm=jpg&q=80&w=2400&auto=format&fit=crop
Photographer: Noah Buisson (Unsplash License — free to use, credit appreciated but not required)
Source page: https://unsplash.com/photos/fresh-vegetables-displayed-in-wooden-crates-at-market-XPltBlxfChk

Right-click the download link → "Save link as..." → save as
`images/market-produce.jpg` in this exact folder.

## Note on contrast

The hero text is white, sitting on a dark-to-green gradient overlay on
top of the photo. A busier or lighter photo may need the overlay darkened
slightly — if the headline gets hard to read once your photo is in,
tell me and I'll adjust the `.hero-overlay` opacity in the CSS.
